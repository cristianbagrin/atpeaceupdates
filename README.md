# at-peace-updates

The old update channel for At Peace copies installed from a file (versions up to 0.3.3).

Its last entry moves those copies to 0.5.0 from addons.mozilla.org. That version updates from
addons.mozilla.org from then on, so nothing new is published here.

Install At Peace: [addons.mozilla.org/firefox/addon/atpeace](https://addons.mozilla.org/firefox/addon/atpeace/)
or the file itself, [latest.xpi](https://addons.mozilla.org/firefox/downloads/latest/atpeace/latest.xpi).
Either way it keeps itself up to date.
